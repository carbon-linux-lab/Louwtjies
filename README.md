Louwtjies GitHub Repo

Hello Louwtjie Ouer/Leerder, die is `n verniet, vriendelike taak bedoel vir Louwtjies om mini-games vir al Jou vakke te kry.
As jy weet hoe GitHub werk, great, jy kan als vinnig verniet download.

Voel jy bietjie verlore, ja, GitHub kan nogals besig wees. Weet net as jy baie kode sien, dis normaal, jy het dalk net verkeerd geclick.
Hoe om maklik als te download:

Stap 1:
Vind die knoppie in die boonste-regter hoek waar daar "Code" (Groot Groen Knoppie) daarop staan.

Stap 2:
Klik op dit en kyk vir die "Local" Tab , onder sal jy `n opsie vind waar jy "Download ZIP" kan gebruik

Stap 3:
Vind dit in jou downloads in File Explorer (Windows) of Finder (MacOS), extract die contents van die .zip genoem "Louwtjie-main.zip"

Stap 4:
Double-click een van die games en dit sal reg daar in jou browser (bv. Google Chrome, Firefox, Brave, Safari) oop maak sonder om enige iets te installeer. 

Geniet die Mini-Games!
